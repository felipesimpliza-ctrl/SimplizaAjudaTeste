# Exportar XML das notas emitidas

Use esta função para exportar os arquivos XML das notas emitidas.

## Exportar os arquivos

1. Acesse a área fiscal do Simpliza.
2. Localize a consulta das notas emitidas.
3. Selecione o período ou os documentos desejados.
4. Execute a exportação.
5. Salve os arquivos em um local seguro.

## Se o download não iniciar

O navegador pode estar bloqueando pop-ups ou redirecionamentos.

1. Clique no ícone de configurações ao lado do endereço do site.
2. Abra as configurações do site.
3. Localize **Pop-ups e redirecionamentos**.
4. Permita o recurso para o site da Simpliza.
5. Tente a exportação novamente.

> **Boa prática:** mantenha os arquivos fiscais organizados por período e faça cópias de segurança conforme a política contábil da empresa.
