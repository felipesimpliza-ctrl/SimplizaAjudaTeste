# Comece por aqui

A Central de Ajuda foi organizada para que você encontre rapidamente o procedimento necessário.

## Antes de começar

Para tarefas de configuração, tenha em mãos:

- os dados usados no cadastro da empresa;
- acesso ao usuário administrativo `adm`;
- acesso às integrações que serão configuradas, quando aplicável.

## Como encontrar um artigo

Pesquise pelo nome da tarefa ou por palavras-chave. Exemplos:

- `Mercado Pago`
- `taxa de entrega`
- `impressora`
- `NCM`
- `Cardápio Digital`

## Artigos recomendados

Se você está configurando o Simpliza pela primeira vez, comece pela configuração do cadastro, produtos e Cardápio Digital. Depois, avance para vendas, pagamentos, fiscal e equipamentos conforme a operação do estabelecimento.
