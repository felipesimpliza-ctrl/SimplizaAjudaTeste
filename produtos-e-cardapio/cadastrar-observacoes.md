# Cadastrar observações

Use observações para permitir que o cliente ou atendente informe particularidades do pedido.

## Procedimento

1. Acesse **Cardápio**.
2. Entre em **Observações**.
3. Cadastre a observação desejada.
4. Salve as alterações.
