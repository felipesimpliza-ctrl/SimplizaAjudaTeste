# Editar preço de um produto

Use este procedimento para alterar o valor de venda de um produto já cadastrado.

1. Acesse a área administrativa.
2. Entre em **Cardápio → Produtos**.
3. Localize o produto.
4. Edite o preço.
5. Salve a alteração.

> **Nota de migração:** validar a interface atual antes da publicação.
