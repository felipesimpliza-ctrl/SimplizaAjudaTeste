# Criar usuário de garçom

1. Acesse a área administrativa.
2. Crie um novo usuário.
3. Defina uma senha que atenda aos requisitos exibidos pelo sistema.
4. Selecione o tipo de usuário **Garçom**.
5. Defina o **Caixa Responsável**, quando aplicável.
6. Clique em **Cadastrar** e confirme.

> O artigo original informa que o usuário do tipo Garçom é destinado ao aplicativo do Garçom.
